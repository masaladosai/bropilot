# BroPilot

AI-powered CLI assistant for GitHub automation and developer workflows.

BroPilot can:

- Create GitHub repositories
- Manage repository files
- Update files with commits
- Delete files
- Inspect repositories
- Run AI-powered GitHub tasks from natural language

---

# Installation and setup

## 1. Clone the repository and install

```bash
git clone https://github.com/masaladosai/bropilot.git
cd bropilot
pip install -e .
```

prompting:
  bropilot "get all my repos"

  
#it will need github token and gemini api key when running for first time...make sure to give github token repo access
